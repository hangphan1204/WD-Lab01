IMAGES

This page demonstrates how HTML can organize images together with descriptive text and semantic structure.

Image Demonstration 1

Figure 1 shows a snowy mountain landscape beside a calm blue lake. In the original sample, the image appeared on the left side of the text. In this Lab01 page, the content is organized using HTML only, without CSS positioning.

Image Demonstration 2

Figure 2 shows an astronaut floating in space above the Earth. In the original sample, the image appeared on the right side of the text. In this exercise, the image and paragraph are grouped semantically using HTML elements.

Image Demonstration 3

Figure 3 presents a book cover about creating web pages. This additional example shows that HTML can organize many different kinds of media content, not only photographs but also illustrations and learning materials.

Semantic Note

In each example, the figure element acts as the parent, while img and figcaption are child elements. This structure helps keep the image and its caption together in one meaningful content block.
